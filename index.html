About me

I build React and TypeScript interfaces that run inside customers' own Microsoft 365 tenants, and I own each feature from the first commit through testing and release.

For 4.5+ years I have been a core developer on Ideagen's Policy Management platform, a compliance product used by global enterprises. I deliver features across policy creation, library, certification and administration, and I maintain the shared component library that several projects build on.

I also work daily with AI coding agents (Claude Code and Cursor CLI). Project conventions live in Cursor rules files, so generated code follows the same SPFx patterns as the rest of the codebase.

Try the bug I fixed

A Fluent UI Switch used defaultChecked, so it only read its value once. When the workflow was reset in code, the switch still showed the old value while the workflow state said otherwise. Press Reset workflow and watch the two switches.
